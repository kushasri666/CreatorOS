# Small live comparison — 20 October 2026

**One combined authorized cap: $0.75. Actual reconciled spend: $0.0123379.**
All 31 requests, including invalid outputs in the pilot, are included. Unused
allowance: **$0.7376621**. No images, video, audio, publishing or real customer data.
All AI calls used Mesh. Prices and billing came from authenticated Mesh metadata.

## Method

Three candidates received the same fictional coffee-brand samples, Instagram
brief, fixed voice and explicitly simulated two-format engagement evidence.
The pilot covered brand analysis, strategy, writing, visual prompting and learning.
Writing used an abbreviated schema instruction; both GPT and Gemini returned
`caption` instead of `text`, so those failures are retained as prompt-contract
failures rather than proof of poor content quality. GPT also returned eight slides
when exactly seven were requested. No responses were silently repaired.

A separately labeled main follow-up gave GPT and Gemini the same explicit JSON
schemas, matching CreatorOS's production prompting pattern. Each completed eight
tasks: brand, strategy, writer, editor, visual prompt, learner, revision and final
editor. Every revised caption changed. Voice and evidence were fixed rather than
generated by an upstream candidate, so these are agent-contract comparisons, not
full end-to-end content-production runs.

## What the content actually showed

- GPT's final caption included all five tips and preserved the warmer brand style.
  Its revision mostly changed wording and emojis. The editor's average stayed
  **8.8 → 8.8**; changed wording did not establish a quality improvement. Vague
  advice to steep longer or stir mid-brew still needed contextual human review.
- Gemini produced a shorter caption and distinct slide tips. Its own editor average
  declined **8.4 → 8.0**, noting caption/slide alignment and voice concerns. Both
  revisions passed the format contract; this does not mean both were equally good.
- Both learning outputs inferred that particular wording/tone/CTAs explained the
  engagement difference, although the fixture only compared story vs checklist.
  They therefore **failed the qualitative grounding requirement**. Schema-valid
  output must not be confused with evidence-grounded analysis. The production
  learner prompt was strengthened to forbid these unsupported attributions;
  that change has only offline validation, not another paid comparison.
- DeepSeek returned empty content in four pilot tasks with `finish_reason=length`;
  its reported reasoning tokens consumed the 350–1,000 token caps. The submitted
  `thinking: disabled` did not disable reasoning on this Mesh route. Its strategy
  output was usable and cautious. It was not retested blindly: this is a route/
  configuration incompatibility result, not a claim that the model writes poorly.

## Decision

Keep GPT-4.1 mini for brand voice, writer/rewriter and editor provisionally. Keep
Gemini Flash-Lite for concise strategy and visual prompts. Keep automatic metric
comparisons and API-derived learning grounded in Python's deterministic evidence.
Treat LLM learner interpretations as hypotheses requiring review; neither model
earned autonomous analytics interpretation from this test.

DeepSeek remains inactive until reasoning controls are correctly verified. Jev was
not tested: typed evaluation is a different contract and this run prioritized
the existing content agents. Image/audio/video quality was not compared.

## Budget and reproducibility

`scripts/compare_models.py` persists one ledger in gitignored
`data/model-comparison-075.json`. Pilot and follow-up share it. Every request
reserves an allowance based on UTF-8 prompt bytes plus framing, maximum output,
catalogue rates, six gateway attempts and a margin. Reservations are never
refunded for failed/unknown calls. Total reservations were **$0.32789360**; actual
spend was far lower. An account-balance guard runs before every paid request.
There are no client retries, tools, media calls or automatic premium escalation.

This local reservation is a conservative estimate, not a transactional promise
from Mesh. Gateway billing/routing behavior can change, and unrelated concurrent
account use affects the balance guard. Mesh's own spend cap can be crossed by one
request, so a cap alone would not have been sufficient. No key settings or account
permissions were changed. Observed routing showed no cross-model fallback.

Already-completed runs do not generate again. **Do not delete/reset the ledger**
to repeat the test under the same authorization. Source and sanitized raw outputs
are saved in `model-comparison-075.json`; account identifiers/headers are excluded.

The sample is one brief, one voice and one run per task/model. Self-editor ratings
are biased opinions, not independent evaluations, factual verification or measured
engagement. Do not promote these numbers as a universal best-model ranking.
